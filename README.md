# two_daughter_pk

老大老二 PK 系列 —— 用 AI 视频生成，让两个女儿在「同龄」条件下公平对决的短视频系列。

## 一、项目简介

- **项目定位**：竖屏 AI 短视频系列，每期约 10 秒，一格斗游戏式的「同龄对决」
- **核心创意**：把不同时期的两姐妹放在**同一月龄**下 PK。姐姐用历史影像，妹妹用当期影像，让相差近 8 岁的两人真正站在同一起跑线
- **首发期**：第 1 期，双方均为 **1 月龄**，用两张 1 月龄头像对决

## 二、创作背景

| 角色 | 昵称 | 关系 | 当前状态 | 出生日期 | 面部锚点 |
|---|---|---|---|---|---|
| 姐姐 | 大仙儿 | 老大 | 快 8 岁 | 待补充 | 待解析 |
| 妹妹 | 小汐儿 | 老二 | 约 3 个月 | 待补充 | 待解析 |

> 两人现实中年龄差近 8 年，无法同框竞技；「同龄对决」是让她们可以公平较量、也留住姐姐成长影像的唯一方式。

## 三、核心机制

### 1. 同龄坐标轴

以**月龄**为唯一时间坐标，双方同月龄对决：

| 期数 | 月龄 | 姐姐素材来源 | 妹妹素材来源 |
|---|---|---|---|
| 第 1 期 | 1 月龄 | 大仙儿 1 月龄时影像 | 小汐儿 1 月龄时影像 |
| 后续 | 3 / 6 / 9 / 12 月龄… 逐期推进 | 历史影像归档 | 实时按月补录 |

### 2. 竞技项目（婴儿级对抗）

不做拳击、不使用武器，改为「婴儿式竞技」：

奶量、哭声分贝、踢腿高度、抓握力、抬头时长、吐泡泡连击、翻身速度、笑声感染力、入睡速度、打嗝音量。

### 3. 胜负规则

**绝对公平：轮流各赢一场。** 奇数期姐姐胜、偶数期妹妹胜，各占一半，家庭内部零争议。

### 4. 系列化元素

- **战绩板**：累计比分，每期收尾时更新
- **称号体系**：大仙儿 =「奶量之王」（S01E01）、「奔月速度王」（S01E03）；小汐儿 =「咬饼速度王」（S01E02）。每期胜者可获新称号
- **非人类观众池**：外星小灰人为**常驻观众**（可换装，S01E01-E03 连续使用）；太空猫、玩偶军团、水果家族、表情包生物等作为彩蛋轮换
- **格斗 HUD**：血条改为「奶量条 / 月饼进度条」等主题化表现，含回合数、REPLAY 慢镜角标

## 四、单期节拍表（10 秒基准 / 15 秒加长）

| 时间 | 内容 |
|---|---|
| 0.0 - 1.0s | 冷启动钩子：黑屏 + 「ROUND 1 · 1月龄对决」亮牌 |
| 1.0 - 2.5s | 双人分屏登场亮相 |
| 2.5 - 4.0s | 对峙蓄力（眼神、挑衅表情） |
| 4.0 - 7.5s | 交锋 2-3 拍（动作宁少勿多） |
| 7.5 - 9.0s | 决胜瞬间：升格慢镜 + 定格 |
| 9.0 - 10.0s | 胜利造型 + 比分板 / 称号飘字收尾 |

> 15 秒加长版的对应节拍见 AGENT.md 第 7 节（S01E03 起使用）。

## 五、视觉与音频规格

| 项目 | 规格 |
|---|---|
| 视觉风格 | 2D 萌系卡通（国漫风）为默认；另有**写实真人版**变体（S01E01 起并存，见 AGENT.md 5.1） |
| 面部要求 | **必须提取真实面部特征，相似度优先**（详见 AGENT.md 第 5 节） |
| 画幅 | 竖屏 9:16，1080 × 1920 |
| 时长 | 10 秒（默认）/ 15 秒（主题加长，S01E03 起） |
| 帧率 | 24 - 30 fps |
| 音频 | 中文解说 + 字幕 + 音效（BGM 走擂台感 / 玩具感） |
| 提示词语言 | 中文 + 英文双版（平台待定，先做通用模板） |

### 面部锚点：来源与流程

两个角色的形象一致性，靠「真实参考图 + 7 项面部锚点」保证，流程固定为：

```
真实影像打底 → 逐项解析 7 项锚点 → 校验姐妹差异点 → 回填中英双版提示词
```

7 项锚点维度：脸型轮廓 / 眼睛形状与大小占比 / 眉眼距 / 鼻型 / 唇形 / 发量与发旋呆毛 / 标志性表情。每项写法要求与禁止事项见 AGENT.md 5.4。

- **当前状态**：文字面部锚点**暂无（已决策暂缓）**。身份一致性改由**参考图承担**（图生视频首帧 / 角色参考），详见 AGENT.md 5.2 路径 A
- **素材现状**：S01E01 已有两张 1 月龄**全身图**（`assets/ref/S01E01_大仙儿_1月龄_正脸.jpg`、`assets/ref/S01E01_小汐儿_1月龄_正脸.jpg`）；全身图当面部位占比较小，若走文字锚点（路径 B）精度不足，建议补 1 月龄面部特写
- **参考图位置**：`assets/ref/`（该目录已加入 .gitignore，防止真实儿童影像被提交）
- **核心原则**：身份相似度以参考图为准；若启用文字锚点，必须从参考图实际解析或用户口述得出，严禁用「可爱」「萌」「大眼睛」这类泛化词代替
