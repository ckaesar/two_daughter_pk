## 八、崩坏高发点与预案

| 高发点 | 预案 |
|---|---|
| 握鼓槌的手手指数量异常 | 用短槌、整只小手掌包裹握持，减少手指分叉；必要时只拍槌头不拍手 |
| 面部漂移 / 姐妹撞脸 | 降低 2D 化程度、减小运动幅度，优先保证面部还原 |
| 声波环、金色纸屑、红绸遮挡面部 | 特效只出现在面部轮廓之外，面部特写镜头不带遮挡物 |
| 夜空烟花与灯笼阵过于杂乱抢戏 | 烟花只出现在人物轮廓之外，亮度低于面部 |
| 双槌连击导致手臂变形 | 改用中景 + 拖影遮挡，减少全身大幅度姿态 |
| 15 秒跨段连续性断裂 | 按三段拆分生成后拼接，跨段的服装、道具、光照保持一致 |
| 观众元素被误画成主体 | 外星小灰人只出现在看台区域，不入擂台区 |
| 红金配色过饱和导致吃细节 | 降低背景饱和度，面部与主体保持清晰描边 |
| 真人版 · 皮肤塑料感 / 玩偶感 | 强化「真实皮肤纹理、胎毛、口水光泽、胶片颗粒」描述，避免均匀平光 |
| 真人版 · 恐怖谷 | 缩短面部大特写时长，改用半身近景；避免正脸长时间凝视镜头 |
| 真人版 · 动作违背月龄 | 只保留趴卧抬头、挥臂拍鼓、蹬腿、攥拳等 1 月龄真实动作，不持槌、不站立、不坐 |
| 真人版 · 夜景面部过暗 | 面部单独暖色主光补光，烟花与灯笼只作背景光 |
| 真人版 · 手持鼓槌的手部崩坏 | 鼓槌只作静置道具出现在画面中，不由婴儿握持 |
