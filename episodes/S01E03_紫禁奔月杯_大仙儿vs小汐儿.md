## 七、生成参数与流程

1. **参数**：9:16 · 1080 × 1920 · 24 fps · **15 秒**。
2. **必须上传参考图 A / B**，走图生视频（首帧 / 角色参考），否则相似度不可控。
3. **先跑首帧静帧确认相似度**，达标后再生成视频（AGENT.md 5.2 验收前置）。
4. 15 秒建议拆三段生成后拼接：`0-5.5s` / `5.5-10.5s` / `10.5-15s`（分段点均落在段落交界处）。
5. 英文版用于 Sora / Veo / Runway，中文版用于可灵 / 即梦 / Vidu。

## 八、崩坏高发点与预案

| 高发点 | 预案 |
|---|---|
| 婴儿手指数量异常 | 让手掌不入画，或用广袖 / 短打袖口遮住手掌 |
| 面部漂移 / 姐妹撞脸 | 降低 2D 化程度、减小运动幅度，优先保证面部还原；飞行镜头尤需检查 |
| 服装元素喧宾夺主 | 仙娥装 / 月兔装的装饰密度低于面部，特写时弱化服装细节 |
| 祥云 / 桂花 / 光斑遮挡面部 | 这些元素只出现在面部轮廓之外，特写镜头不带遮挡物 |
| 15 秒长镜头连续性断裂 | 按三段拆分生成后拼接；跨段的服装、道具、光照需保持一致 |
| 飞行镜头肢体扭曲 | 采用中景 + 速度线遮挡，减少全身大幅度姿态 |
| 满月逆光导致面部过暗 | 面部单独补光，逆光仅作用于轮廓 |
| 尿布 / 披帛变披风形变怪异 | 改为「小披风道具」直接披上，不依赖形变 |
